## Cổng phát hành còn chặn

- **CC-T-12A/12B, CC-T-15B:** Chưa có truyền tệp thật giữa hai máy Windows qua relay, so hash, kiểm staging/publish/consent theo đối tượng thật.
- **CC-T-14B:** Chưa có bằng chứng Win+V và Cloud Clipboard trên hai máy với marker kiểm soát.
- **CC-T-16A/16B:** Chưa build và smoke test gói `.exe` Windows 10/11 sạch, chưa ký số, worker đóng gói vẫn là `croccoc-engine-spike.exe`.

**Kết luận QA:** Fix hồi quy frontend đã vượt qua unit test và build; **chưa thể tuyên bố MVP sẵn sàng phát hành** hoặc chốt E2E native. Cần Windows native Go/Wails + môi trường hai máy trước khi đóng các cổng trên.
