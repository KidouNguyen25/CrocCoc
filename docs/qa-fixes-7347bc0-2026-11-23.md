## Điểm chuyển giao cho QA

- StartSend/StartReceive đang preflight thì Shutdown; Shutdown hai lần; GetCrocInfo song song Shutdown; preflight time out giữ pin; đồng thời session đang chạy vẫn bị hủy có hạn.
- Receiver hoàn tất, ngay sau khi finalizer Release cho phép một session mới, kiểm map session cũ đã dọn và metrics terminal chính xác. Phát `FINALIZING` trước `COMPLETED`.
- Request cancel trùng thời điểm worker trả success: state theo gate không stuck BUSY, không báo COMPLETED khi hủy đã thắng.
- IPC throw được retry; snapshot null xác nhận backend đã mất record cho reset ngay; focus/timer/cancel cùng chờ một in-flight probe.
- Chạy script build qua worker modfile + govulncheck, xác minh SBOM Croc local replace/commit/patch hash từ artifact thật (không chỉ lint file JS).
